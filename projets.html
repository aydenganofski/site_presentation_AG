Création d'un site web

Novembre 2025 - BUT 1

Lors du premier semestre de BUT Informatique, j'ai eu l'opportunité de travailler sur un projet de création d'un site web pour une pizzeria fictive, La Trattoria. En équipe de trois, nous devions concevoir un site web selon les besoins et les spécifications du client. Notre site web devait être rapide au chargement, et devait inclure les mentions légales et un formulaire de contact. De plus, nous devions utiliser les images fournies par le client.

Pour plus de détails, vous pouvez consulter le site web hébergé sur GitLab.

Sokoban en JavaFX

Gestion de tournois e-sport

Juin 2026 - BUT 1

Chef de projet d’une équipe de cinq lors du second semestre, nous devions développer une application de gestion de tournois e-sport à partir d'un existant. En plus de la gestion de projet, des tests et de la documentation, j’ai développé le CRUD des joueurs et des jeux ainsi que le système d’inscription aux tournois.

L'application a été développée en Java et JavaFX avec Maven pour la gestion des dépendances et du build, reliée à une base Oracle SQL et versionnée avec Git.

Animation pour un site de mariage

Juillet 2026 - Projet personnel

Pour le mariage de ma cousine, j'ai développé une animation pour le site web du mariage. En cliquant sur l'enveloppe, elle s'ouvre et permet la redirection vers le site web conçu par ma cousine sur Canva. L'enveloppe est entièrement réalisée en CSS et HTML, avec une animation fluide et responsive. L'animation est compatible avec tous les navigateurs modernes et s'adapte à toutes les tailles d'écran.

Création d'un jeu vidéo

Septembre 2026 - Projet personnel

Passionné de jeu vidéo, je me suis lancé le défi de créer mon propre jeu vidéo. J'ai choisi de développer un jeu de type "Life Simulation" en utilisant le moteur de jeu Godot. Le jeu est encore en développement, mais j'ai déjà implémenté le déplacement du personnage principal ainsi que les interactions avec les PNJ. Le but du jeu serait d'incarner un étudiant en informatique, et de gérer sa vie quotidienne entre les cours, les projets et les loisirs.
